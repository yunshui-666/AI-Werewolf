从用户输入到游戏结算

WerewolfArena · 本地浏览器、Python 主持人与 LangGraph 的完整数据路径。

启动与配置打开网页 → 选择板子、座位与逐 Agent APIPOST /api/game/start → SessionOptions 校验 → 创建独立 Agent
↓
身份初始化随机分配身份与人格 → 加载对应角色 SKILL.md真实状态留在 GameEngine，独立记忆通过 PlayerView 提供
↓
LangGraph夜晚行动 → 结算 → 白天讨论 → 投票 → 胜负路由守卫 → 狼人 → 女巫 → 预言家，死亡猎人在胜负判定前响应
↓ 每次轮到某个玩家行动
真人输入创建 request_id，等待网页输入游戏线程释放等待锁 → 页面显示合法候选
你输入发言或选择目标 → POST /api/game/action
AI 决策本人视图 + 角色 skill + 行动 Prompt离线策略或所选 API → JSON 结构化输出
失败时有界重试，再使用合法降级行动
↓
校验与执行Pydantic 校验 → 规则校验 → GameEngine 修改状态核对身份、阶段、目标、次数与药品资源，去重过期输入请求
↓
结算公开事件 → 死亡响应 → 胜负判定狼刀、守护和药品统一计算，待结算选票收齐后公开
↓
页面输出轮询白名单快照 → 圆桌、记录、私有面板与可选朗读语音按公开发言排队播放，终局才统一显示全部身份
↻ 未结束时继续当前流程或下一夜

对照代码阅读

web/static/app.js 提交输入与轮询。web/server.py 处理 HTTP。web/session.py 等待真人输入和管理后台线程。game/runner.py 请求决策。game/rules.py 校验规则。game/engine.py 修改真实状态。workflow/graph.py 编排循环。

API Key 保存在本地配置或后端内存。浏览器收到的是本人可见信息，角色攻略是通用知识，实际角色分配由主持人持有。
