# 狼人杀规则与角色策略研究

检索与阅读日期为 2026 年 11 月 16 日。本次研究为 WerewolfArena 的角色扩展和专属技能文件提供依据，策略内容结合项目的顺序发言、私有记忆和结构化行动接口重新组织。

## 默认采用的 12 人配置

新版采用“预女猎守”配置，包含 4 名普通狼人、4 名村民，以及预言家、女巫、猎人、守卫各 1 名。百科中的“12 人预女猎守”条目和桌游社区的“守护家园”配置均列出这一组合。游戏官网部分文章采用 3 普通狼人加 1 白狼王的守卫场，本版选取普通四狼版本。 [角色配置百科](https://bkso.baidu.com/item/%E5%AE%88%E5%8D%AB/22060648) [桌游社区配置](https://www.ptt.cc/bbs/BoardGame/M.1508852049.A.905.html) [游戏官网守卫场](https://www.langrensha.net/strategy/2022072102.html)

12 人局使用屠边胜利条件。狼人全部死亡时好人获胜，全部村民或全部神职死亡时狼人获胜。已有 8 人配置继续采用 2 狼人、1 预言家、5 村民及原有的人数优势胜负规则，便于已有示例和测试继续运行。 [12 人胜负说明](https://www.langrensha.net/strategy/2022071102.html)

## 本版确定的房规

| 项目 | 本版处理 |
| --- | --- |
| 女巫药物 | 整局一瓶解药、一瓶毒药，同夜最多使用一种 |
| 女巫自救 | 全程不能自救 |
| 女巫刀口信息 | 解药未使用时可看当夜狼刀目标，解药用完后停止提供 |
| 守卫目标 | 可空守、自守、守护存活玩家，连续两晚目标不同 |
| 守护范围 | 抵挡狼刀，毒药穿过守护 |
| 同守同救 | 守卫与解药作用于同一狼刀目标，该目标死亡且药物消耗 |
| 猎人技能 | 被刀或放逐后可选择开枪，也可放弃，被毒后不能开枪 |
| 响应结算 | 猎人响应处理完成后，再根据最终存活状态判定胜负 |
| 胜负优先级 | 先检查狼人全灭，再检查屠边，最后检查最大完整轮数 |
| 死亡公告 | 公布死亡编号，完整身份在终局展示 |
| 普通发言 | 按存活编号进行，默认两轮 |
| 投票平票 | 最高票并列时无人出局 |
| 狼人意见分歧 | 存活狼人最小 ID 作为固定裁决者 |
| 狼刀目标 | 12 人局可选任意存活玩家，包括自刀和队友，8 人局保留仅刀其他好人的原规则 |

药物、保护交互与刀口可见性参考常见规则手册，具体状态以项目中选定的房规实现为准。 [规则速查](https://hi8.com/g/langrensha/guize) [守卫能力说明](https://bkso.baidu.com/item/%E5%AE%88%E5%8D%AB/22060648)

不同来源在女巫首夜自救、平票 PK、警长流程和猎人判定时机上存在版本差异。项目把这些差异明确化为上表规则。警长、警徽、白狼王和狼人白天自爆列为后续扩展项，当前流程继续按编号发言和普通投票。攻略中依赖警徽或白狼王的建议，转化为普通查验计划与公开讨论中的策略。 [常见流程与变体](https://hi8.com/g/langrensha/guize)

## 攻略归纳与技能文件

| 角色 | 本版策略重点 | 专属文件 |
| --- | --- | --- |
| 狼人 | 伪装记录一致、队友分工、控票、切割与夜间目标价值 | `role_skills/werewolf/SKILL.md` |
| 预言家 | 查验信息价值、可复核的逐夜记录、对跳回应与公开时机 | `role_skills/seer/SKILL.md` |
| 村民 | 公开证据整合、站边理由、投票一致性与新证据后的调整 | `role_skills/villager/SKILL.md` |
| 女巫 | 有限药物的时机、守救交互、对获救者持续验证 | `role_skills/witch/SKILL.md` |
| 猎人 | 存活期积累证据、开枪误伤成本、响应时合法目标选择 | `role_skills/hunter/SKILL.md` |
| 守卫 | 保护路径、避免连续同守、反刀与公开保护记录的取舍 | `role_skills/guard/SKILL.md` |

攻略共同强调角色视角与前后行为一致。狼人需要让伪装叙述可持续，好人需要把事实、声称和猜测区分清楚。首夜解药和空守在攻略中经常配套出现，本版把它们作为决策建议，玩家可在合法范围内保留药物或选择其他保护路线。 [角色发言建议](https://www.langrensha.net/strategy/2021110102.html) [女巫与预言家策略讨论](https://www.langrensha.net/strategy/2021030501.html)

技能文件属于游戏内角色知识。主持人在身份分配后加载对应角色文件，LLM 获得该角色的目标、合法边界、可见信息与策略建议，真实状态仍由 Python 规则执行。角色策略文件可以独立编辑，以便学习 Prompt 与行为变化的关系。
